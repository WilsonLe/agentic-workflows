# Learn from reference

Resolve the exact user-provided file, URL or time range. Use available playback,
source frames and audio; YouTube retrieval follows an installed YouTube workflow
when needed and authorized. A thumbnail or description is evidence only for that
surface. Separate what was watched/listened to from inferred or unavailable detail.

Build a timestamped breakdown of the reference's hook, shot lengths, framing,
camera movement, subject continuity, transitions, color, text hierarchy, keyframe
rhythm, dialogue, musical accents and ending. Read text size relative to its canvas;
do not claim an exact font or easing curve from pixels without supporting evidence.
For sound, note pauses, layer entrances, speech/music balance and cue placement.

Translate useful observations into the current brief: which technique, why it
helps, which beat receives it, how it changes for this audience/assets, and how
to check the result. For example, a readable hold before a fast reveal can become
an original title/shot sequence. Test a short representative segment before making
the entire cut. Preserve the user's accepted style rather than copying every effect.

Record the reference URL/path, inspected ranges and limitations beside the
storyboard. Use reference-derived ideas with original or authorized assets; source
access does not establish redistribution or soundtrack rights. Do not infer voice
cloning permission from a reference speaker. If access fails, continue with a stated
style assumption or request the missing reference through the normal conversation.

# Trend to Product

An evidence-first Codex plugin that persists demographic trend tracking and
trend-to-product artifacts inside an explicitly selected project.

It provides five skills for onboarding, discovery, opportunity reasoning,
design generation, and drop operations plus a dependency-free Python CLI. Live
sources, schedulers, image tools, and stores remain external capabilities with
separate authorization.

```bash
python scripts/trend_to_product.py project-init \
  --project /absolute/project --git-policy mixed
python scripts/trend_to_product.py validate --project /absolute/project
```

The plugin never reproduces a person's FYP, harvests browser credentials,
publishes products, or claims generated concept art is print-ready.

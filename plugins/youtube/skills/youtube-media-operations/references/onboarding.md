# YouTube media onboarding

Run preflight from the plugin root and confirm yt-dlp, FFmpeg/ffprobe, and Deno or Node. Public mode
needs no credentials. Account-gated mode additionally needs the protected cookie-file workflow in
`cookie-authentication.md`.

Before downloading, obtain:

- exact YouTube URL(s);
- requested video/audio/section/live output and bounds;
- explicit output root;
- a user-stated rights basis;
- whether public access is sufficient.

Never install dependencies or retrieve media merely to prove readiness.

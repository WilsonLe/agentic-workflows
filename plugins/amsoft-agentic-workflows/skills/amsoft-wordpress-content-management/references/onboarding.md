# WordPress Content first use

Resolve the local WordPress URL, the live WordPress URL when live delivery is requested, and an
existing authorized REST, administrator, or WP-CLI path. If an Application Password is used, read
[application-password-contract.md](application-password-contract.md).

Then inspect the local active theme, registered blocks, available patterns, relevant pages/posts,
and affected media. Do not create setup documents, repository records, branches, issues, commits, or
pull requests. Prepare task payloads in a private temporary directory and proceed through the normal
local-first workflow.

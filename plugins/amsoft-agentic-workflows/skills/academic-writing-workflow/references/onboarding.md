# Academic Writing onboarding

Use this guide when a user asks to set up, onboard, or get started with the Academic Writing workflow.

## What to collect

Ask the user to provide or identify:

- the complete task sheet, rubric, submission instructions, and supplied sources;
- the deliverable type, deadline and timezone, target word count, citation style, and required file format;
- the institution's AI-use and academic-integrity rules;
- any existing outline, draft, research notes, data, screenshots, reflection, or other student-owned evidence;
- the folder where the project should be created, if the user has a preference.

Preserve unknowns as unresolved items. Do not turn a missing requirement into an assumption.

## First-run workflow

1. Confirm that the task sheet and integrity rules can be read in full.
2. Summarize the known requirements and list only the missing information that would materially affect the plan.
3. Explain the six stages: execution plan, high-level outline, verified research, detailed outline, first draft, and final version.
4. Explain that each stage stops for explicit review and that silence is not approval.
5. After the user confirms the working scope, initialize the project workspace and create only the Stage 1 execution plan.
6. Return the plan for review. Do not continue to the outline or draft during onboarding.

## Ready state

The workflow is ready when the source materials are accessible, the integrity boundary is known, the project location is agreed, and the user understands the review gates. Internet and PDF access are also required before the verified-research stage.

## Suggested first prompt

> Onboard me to Academic Writing using this task sheet. First summarize the requirements, identify any missing information, and explain the review gates. Do not draft the assignment yet.

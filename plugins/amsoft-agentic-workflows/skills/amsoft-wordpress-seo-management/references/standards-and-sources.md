# Standards and sources

Search features, spam policies, structured-data eligibility, WordPress APIs, and platform behavior
change. Recheck primary documentation before applying a time-sensitive requirement. Record the page
and access date in material audits.

- [Helpful, reliable, people-first content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)

- [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)
- [Crawling and indexing documentation](https://developers.google.com/search/docs/crawling-indexing)

Use a search engine's own documentation for its eligibility and policy claims. Use WordPress core
documentation for core behavior, then the installed SEO plugin's current official documentation for
plugin-specific fields and workflows. Treat third-party studies and tool metrics as supplementary
evidence with named methodology and limitations.

# Guided Writing Coach

Guided Writing Coach helps a user turn an outline and detailed reference into
their own paragraph through a multi-turn chat. The user writes; the coach
compiles that wording, checks whether it expresses the intended idea, and asks
one focused question about what to write next.

The plugin includes `guided-writing-coach`, an instruction-only skill for:

- working on one target paragraph at a time;
- accepting a sentence, clause, fragment, bullet, or full revision on each turn;
- keeping a visible working paragraph made only from user-supplied wording;
- checking coverage, factual accuracy, attribution, and coherence against the
  supplied outline and detailed reference; and
- letting the user accept the paragraph or keep revising it.

## Authorship boundary

The detailed reference is a meaning benchmark, not a prose bank. The coach
does not silently write, polish, substitute, delete, or reorder the user's
paragraph. It may propose a structural edit, but applies it only after the user
explicitly approves it. It does not claim to prove authorship or help evade AI
or plagiarism detection.

Academic and third-party material still requires the attribution and permitted
AI assistance required by the user's institution, publisher, workplace, and
source licenses. Requests for automatic rewriting belong in Humanizer;
research-led academic drafting belongs in Academic Writing when those
workflows are installed.

## Runtime

No runtime, account, credential, provider, script, schema, MCP server, or app is
bundled. Start a new Codex session after installing or updating the plugin so
the skill is discoverable.

# Onboarding

Install the package for your harness, then choose the relevant skill from the router. Each skill has a generated Prerequisites section. Configure only the tools and accounts required for the chosen workflow.

For Codex, add this private GitHub marketplace and install `agentic-workflows@agentic-workflows`. For Claude Code, add this repository as a marketplace and install the `agentic-workflows` package. The Claude distribution contains only skills declared compatible with Claude Code.

See the repository [README](../../../../../README.md) and [harness guide](../../../../../docs/harnesses.md) for the exact commands and support matrix.

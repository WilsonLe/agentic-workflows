# Typography

Build the text system for the actual canvas, language and viewing context. Reuse
an existing design system/font library first. Read [font library and layout](references/font-library-and-layout.md)
for discovery, static font downloads/indexing, shaping, formatting and verification.

Support broad font discovery from authorized local fonts, foundries and libraries;
select and download the styles needed for this piece. Do not claim exhaustive
coverage of every font. Maintain a reusable indexed local library without bulk
downloading unrelated collections. Keep font files/license records with the edit's
assets, outside source Git by default. Paid font purchases require their own authority.

Record family/style/weight/width, supported scripts and license separately from
editorial labels such as display, serif, monospace, restrained or playful. Only label
a font after inspecting it; a filename is not a reliable family or coverage record.

Set hierarchy, font size, weight, line height, tracking, alignment, safe margins,
wrapping, contrast and caption holds from the brief and actual delivery size.
Use Motion Design for kinetic text/keyframes and Video Editing for placement/caption
timing. Return explicit font IDs and layout values to the timing owner; typography
does not create another animation clock. For a standalone layout this skill owns it.

Deliver font index and assets/licenses, text/layout specification and rendered
specimens or title/caption frames. Check glyphs, shaping, line breaks, fallback,
overflow and phone readability in the encoded video when applicable. Font loading
or source CSS alone cannot prove the intended face rendered. Font/style/text
changes invalidate affected frames and final review evidence. Missing glyphs or
license evidence require a suitable fallback or an explicit unresolved limit.

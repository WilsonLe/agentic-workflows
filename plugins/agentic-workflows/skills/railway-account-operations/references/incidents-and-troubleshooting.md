# Railway incidents and troubleshooting

Use [Codex connected apps](../../agentic-workflows/references/service-browser-operations.md).
Resolve connected identity, exact workspace/project/environment/service, and the
incident window before bounded structured reads. Inspect actual tool schemas and
provider instructions; do not restore a CLI wrapper when a capability is missing.

Recover missing/expired connections through Codex. Report authorization or missing
tool support without broader tokens, account switching, or dashboard fallback.
Follow bounded tool retry guidance for reads; unknown write outcomes need saved-state
readback before another mutation. Keep deployment/log results bounded and sanitized;
never dump environment values, credentials, private records, or raw traces.

Separate diagnosis from mitigation authority. Present evidence, hypothesis, blast
radius, smallest reversible action, verification, and recovery. Reuse an existing
request covering that exact emergency effect, apply one change at a time, and
stop when stable or when the next step broadens the authorized scope. Observe
terminal deployment state and live health before claiming recovery.
